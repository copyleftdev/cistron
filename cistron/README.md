# cistron

The core primitive for the genome and the rules that apply to it: a
convention-safe located allele (interbase coordinates, reference agreement) with
left-aligned, parsimonious `normalize` — validated byte-for-byte against
`bcftools norm` and mutation-tested to zero survivors.

Part of the [cistron workspace](https://github.com/copyleftdev/cistron).
