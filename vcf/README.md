# cistron-vcf

The VCF boundary for [`cistron`](https://crates.io/crates/cistron): 1-based
anchored records <-> interbase blunt variants. The anchor base trims away under
`normalize`; emit re-introduces one from the reference.

Part of the [cistron workspace](https://github.com/copyleftdev/cistron). MIT OR Apache-2.0.
